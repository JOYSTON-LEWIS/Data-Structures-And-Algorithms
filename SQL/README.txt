Round 0 SQL Practice (SQL Server / SSMS)

Files:
00_All_SQL_Practice_Combined.sql - all five exercises in one script.
01_Second_Highest_Salary.sql - second-highest distinct salary.
02_Inner_vs_Left_Join.sql - INNER JOIN and LEFT JOIN.
03_Group_By_Having.sql - GROUP BY, HAVING, and WHERE.
04_Find_Duplicate_Rows.sql - find duplicate emails and matching rows.
05_Delete_Truncate_Drop.sql - DELETE, TRUNCATE, and DROP.

How to run:
1. Open a file in SQL Server Management Studio (SSMS).
2. Connect to a SQL Server instance.
3. Press Execute (F5).
4. Review the Results tab.

These scripts use local temporary tables (names beginning with #), not permanent tables.
They can be run independently. The combined script runs all five exercises.
